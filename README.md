# پویا (Pouya)

اپ آموزشی فارسی با شخصیت انیمیشنی «پویا» — چت، تمرین زبان، آزمون، مغز دوم (یادداشت)، و گفتگوی صوتی.

> **اعضای تیم:** تاریخچه کامل پروژه، معماری، envها و بدهی فنی در  
> [`docs/TEAM-HANDOFF.md`](./docs/TEAM-HANDOFF.md)  
> نقشه نقش مربی/دانش‌آموز: [`docs/phase-a-roles.md`](./docs/phase-a-roles.md)  
> ریپو را بدون تصمیم عمدی Public نکنید.

## امکانات

- **گفتگو** — چت متنی، پیوست عکس/جزوه، تاریخچه محلی
- **زبان** — تمرین مکالمه
- **گفتگوی صوتی** — تایپ یا میکروفون + TTS (فقط تب گفتگو / صفحه صدا)
- **آزمون** و **مغز دوم**
- **مربی‌ها** و تب حساب

## پشته فنی

| بخش | فناوری |
|-----|--------|
| فریم‌ورک | TanStack Start (React 19 + Vite) |
| استایل | Tailwind CSS v4 |
| UI | Radix |
| AI | لایه در `src/lib/ai.ts` (OpenAI-compatible / Gemini + fallback محلی) |
| دیپلوی | Vercel |

## اجرا

```bash
npm install
npm run dev
```

پورت پیش‌فرض: `8080`.

کلیدهای AI را فقط در متغیر محیطی (مثلاً Vercel) بگذارید — هرگز در کد کامیت نکنید.

## ساختار

```
src/components/   # UI اصلی پویا
src/lib/          # ai، تاریخچه، vault، topics
docs/             # اسناد تیم و معماری
```
