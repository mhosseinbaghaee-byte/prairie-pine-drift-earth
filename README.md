# پویا (Pouya)

اپ آموزشی-همراه با شخصیت انیمیشنی «پویا» — یک دستیار چت، آزمون‌ساز (کوییز) و صندوق یادداشت برای یادگیری.

## امکانات

- **چت** — گفتگوی متنی و صوتی با پویا (تبدیل متن به گفتار)
- **کوییز** — آزمون بر اساس موضوعات و سطح‌های مختلف
- **صندوق (Vault)** — ذخیره و مدیریت یادداشت‌ها در فولدرهای مجزا
- شخصیت انیمیشنی با حالت‌های idle / talk / intro (ویدیو + تصویر)
- پشتیبانی از سطح‌بندی سنی (`Level`) و موضوعات درسی متنوع

## پشته‌ی فنی

| بخش | فناوری |
|---|---|
| فریم‌ورک | TanStack Start (React 19 + Vite) |
| استایل | Tailwind CSS v4 |
| کامپوننت‌ها | Radix UI |
| دیتابیس | PGLite (محلی) / Postgres (در صورت فعال‌سازی) |
| احراز هویت | Better Auth (پیش‌فرض غیرفعال) |
| هوش مصنوعی | چندفروشنده (زیر را ببینید) |
| دیپلوی | Vercel (پریست Nitro) |

## هوش مصنوعی — چندفروشنده، بدون وابستگی به یک شرکت

اپ دیگه قفل روی گروک نیست. `src/lib/ai.ts` یک لایه‌ی یکپارچه داره که از چهار ارائه‌دهنده پشتیبانی می‌کند:

- **Anthropic (Claude)**
- **OpenAI (GPT)**
- **xAI (Grok)**
- **Google (Gemini)**

فقط ارائه‌دهنده‌هایی که کلید API‌شان تنظیم شده باشد امتحان می‌شوند. ترتیب پیش‌فرض:
`anthropic → openai → xai → gemini`. اگر یکی جواب نداد (کلید نداشت، quota تمام شده بود، یا خطای شبکه)، به‌صورت خودکار سراغ بعدی می‌رود.

### متغیرهای محیطی

| متغیر | برای |
|---|---|
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | Claude (پیش‌فرض مدل: `claude-sonnet-4-5`) |
| `OPENAI_API_KEY` / `OPENAI_MODEL` | GPT (پیش‌فرض مدل: `gpt-4o-mini`) |
| `XAI_API_KEY` / `XAI_MODEL` | Grok (پیش‌فرض مدل: `grok-4.5`) |
| `GEMINI_API_KEY` / `GEMINI_MODEL` | Gemini (پیش‌فرض مدل: `gemini-2.0-flash`) |
| `AI_PROVIDER_ORDER` | ترتیب دلخواه، مثلاً `openai,anthropic` |

فقط کافیست حداقل یکی از کلیدها را تنظیم کنید تا چت، کوییز، و «دانستی روزانه» کار کنند.

> نکته: نام دقیق مدل هر فروشنده ممکن است در طول زمان تغییر کند — قبل از دیپلوی نهایی، مقدار `*_MODEL` را با آخرین مستندات همان فروشنده چک کنید.

### صدا (Text-to-Speech)

فقط xAI و OpenAI برای تبدیل متن به گفتار وایر شده‌اند (اول xAI امتحان می‌شود، بعد OpenAI). اگر هیچ‌کدام تنظیم نشده باشند، اپ بی‌صدا به حالت فقط-متن برمی‌گردد — خطایی نمی‌دهد.

## اجرای محلی

```bash
npm install
npm run dev
```

روی پورت `8080` بالا می‌آید.

## بیلد

```bash
npm run build
```

## تنظیمات auth/دیتابیس

وضعیت auth و دیتابیس در `.grok/app-env.json` مشخص می‌شود:

```json
{
  "VITE_AUTH_ENABLED": "false",
  "deploy": { "database": false }
}
```

در حالت پیش‌فرض (auth خاموش، بدون دیتابیس)، دیپلوی روی Vercel بدون نیاز به متغیر محیطی اضافه (به‌جز حداقل یک کلید AI) انجام می‌شود.

## ساختار پوشه‌ها

```
src/
  components/     # پویا-اپ، صحنه، UI
  lib/             # ai.ts (چندفروشنده), app-data, vault, topics
migrations/        # اسکیمای دیتابیس (فقط در صورت فعال بودن auth/db)
public/pouya/       # مدیای شخصیت (idle, talk, intro, portrait)
```
